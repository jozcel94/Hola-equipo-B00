\# Common File Formats in RNA-Seq Analysis



This document describes the most frequently used file formats in an RNA-Seq analysis workflow.



\---



\## FASTQ



\*\*Purpose\*\*



Stores raw sequencing reads together with their quality scores.



\*\*Extension\*\*



`.fastq` or `.fastq.gz`



\*\*Example\*\*



```

sample\_R1.fastq.gz

sample\_R2.fastq.gz

```



\---



\## FASTA



\*\*Purpose\*\*



Contains DNA or RNA reference sequences used during alignment.



\*\*Extension\*\*



`.fa` or `.fasta`



\*\*Example\*\*



```

GRCh38.fa

```



\---



\## GTF



\*\*Purpose\*\*



Genome annotation file containing information about genes, exons and transcripts.



\*\*Extension\*\*



`.gtf`



\*\*Example\*\*



```

Homo\_sapiens.GRCh38.gtf

```



\---



\## SAM



\*\*Purpose\*\*



Stores sequence alignment information in text format.



\*\*Extension\*\*



`.sam`



\---



\## BAM



\*\*Purpose\*\*



Compressed binary version of a SAM file.



\*\*Extension\*\*



`.bam`



\---



\## CSV



\*\*Purpose\*\*



Stores tabular results such as gene expression values.



\*\*Extension\*\*



`.csv`



\---



\## HTML



\*\*Purpose\*\*



Stores quality control reports generated by FastQC.



\*\*Extension\*\*



`.html`



\---



\# Summary



These file formats are commonly used throughout RNA-Seq pipelines and are essential for processing, analyzing and interpreting sequencing data.
