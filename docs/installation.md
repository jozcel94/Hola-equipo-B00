\# Installation Guide



This document describes the software required to prepare an environment for RNA-Seq analysis.



\## Required Software



\- Git

\- R (version 4.4.0 or later)

\- RStudio

\- FastQC

\- Trimmomatic

\- HISAT2

\- SAMtools

\- FeatureCounts



\## Installing R



Download the latest version from:



https://cran.r-project.org



\---



\## Installing RStudio



Download RStudio Desktop from:



https://posit.co/download/rstudio-desktop/



\---



\## Installing Git



Download Git from:



https://git-scm.com/downloads



\---



\## Installing FastQC



Download FastQC from:



https://www.bioinformatics.babraham.ac.uk/projects/fastqc/



\---



\## Installing HISAT2



Download HISAT2 from:



https://daehwankimlab.github.io/hisat2/



\---



\## Installing SAMtools



Download SAMtools from:



https://www.htslib.org/



\---



\## Installing FeatureCounts



FeatureCounts is distributed through the Subread package:



https://subread.sourceforge.net/



\---



\# Verification



After installing the software, verify that each program is available from the command line before starting the RNA-Seq workflow.
