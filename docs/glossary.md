\# Bioinformatics Glossary



This glossary provides definitions of common terms used in RNA-Seq analysis and bioinformatics.



\---



\## RNA-Seq



A next-generation sequencing (NGS) technique used to analyze the transcriptome by measuring RNA expression levels.



\---



\## Transcriptome



The complete set of RNA transcripts expressed by a cell, tissue or organism under specific conditions.



\---



\## Gene Expression



The process by which genetic information is used to produce functional RNA or proteins.



\---



\## FASTQ



A text-based file format that stores raw sequencing reads together with their corresponding quality scores.



\---



\## FASTA



A file format used to store nucleotide or protein sequences.



\---



\## GTF (Gene Transfer Format)



A file containing genome annotation information, including genes, transcripts and exons.



\---



\## Alignment



The process of mapping sequencing reads to a reference genome.



\---



\## Reference Genome



A representative genome sequence used as a template for read alignment.



\---



\## BAM



A compressed binary version of a SAM file used for efficient storage of sequence alignments.



\---



\## Differential Gene Expression



The comparison of gene expression levels between two or more biological conditions.



\---



\## Biomarker



A measurable biological characteristic used for diagnosis, prognosis or prediction of treatment response.



\---



\## Quality Control (QC)



Procedures used to evaluate sequencing quality before downstream analysis.



\---



\## Adapter Trimming



The removal of adapter sequences and low-quality bases from raw sequencing reads.



\---



\## Count Matrix



A table containing the number of sequencing reads assigned to each gene across multiple samples.



\---



\## Normalization



A statistical procedure that adjusts gene expression counts to allow accurate comparison between samples.



\---



\## DESeq2



An R/Bioconductor package used for differential gene expression analysis based on count data.



\---



\## Pathway Analysis



A downstream analysis used to identify biological pathways enriched in differentially expressed genes.
