\ RNA-Seq Analysis Workflow



\ Objective



Describe the main stages of an RNA sequencing (RNA-Seq) analysis pipeline.



\ Workflow



\ 1. Data Acquisition

Obtain raw sequencing data in FASTQ format.



\ 2. Quality Control

Assess sequencing quality using FastQC.



\ 3. Read Trimming

Remove adapters and low-quality bases using Trimmomatic.



\ 4. Alignment

Align sequencing reads to the reference genome using HISAT2.



\ 5. Gene Quantification

Estimate gene expression levels using FeatureCounts.



\ 6. Differential Expression Analysis

Identify differentially expressed genes using DESeq2.



\ 7. Visualization

Generate PCA plots, heatmaps and volcano plots to interpret the results.



\ Expected Results



A reproducible workflow that identifies differentially expressed genes from RNA-Seq data.
